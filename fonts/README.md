# Font Requirements — BUMN Report Formatter

Sistem desain BUMN Taskforce & DAMRI Report Formatter menggunakan tipografi standar **Arial**:

| Peran | Font Family | Keterangan |
|---|---|---|
| **Semua Elemen (All Elements)** | **Arial** (Regular, Bold) | Font universal standar sistem (macOS, Windows, Linux, iOS, Android) |

### Keunggulan Pemilihan Font Arial
1. **Zero Missing Font Issues**: Tersedia secara default di semua komputer dan platform tanpa perlu instalasi font eksternal (`.ttf`/`.otf`).
2. **Consistent Layout & No Clipping**: Metrik font terstandarisasi, mencegah overflow teks atau wrapping yang berantakan ketika deck dipresentasikan di perangkat pimpinan/stakeholder.
3. **High Readability**: Memiliki tingkat keterbacaan yang sangat tinggi untuk data-dense slide (matriks 2x2, tabel analitis, kurva booking, dan roadmap implementasi).
